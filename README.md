## ⚡ Características Principales

* **🔒 100% Operativa Offline:** Diseñada para funcionar en zonas sin cobertura o garajes; no requiere conexión a internet ni consumo de datos.
* **🚨 Comandos de Emergencia:** Acceso directo con un solo toque a comandos de control de alto impacto.
* **🔊 Pronunciación Táctica (TTS):** Reproducción de voz nativa en local para guiar la pronunciación correcta.
* **🔍 Buscador Instantáneo:** Filtrado rápido por palabras clave tanto en español como en inglés.
