# Local Police English (Marbella)

Aplicación oficial para dispositivos Android dirigida a los agentes de la policía local. Diseñada específicamente para proporcionar recursos lingüísticos y términos de alta utilidad operativa en el servicio diario.

## 🚀 Características Principales

* **Vocabulario Operativo**: Terminología policial específica adaptada a intervenciones comunes en vía pública y atención al ciudadano.
* **Acceso Rápido**: Interfaz optimizada para consultas ágiles sobre el terreno.
* **Autonomía**: Funcionamiento completo sin dependencia de conexión constante a la red.

## 📥 Descarga e Instalación

Para instalar la última versión oficial directamente en un terminal Android, accede al canal de distribución automatizado:

* **[📥 Descargar última versión de la APK (Release)](https://github.com/MacSalvi/local-police-english-apk/releases/latest)**

### Instrucciones de Instalación
1. Pulsa sobre el enlace de descarga anterior desde el dispositivo Android.
2. Descarga el archivo ejecutable **`app-debug.apk`**.
3. Ejecuta el archivo descargado y concede los permisos necesarios para completar la instalación de la aplicación.
