## 📱 Descripción del Proyecto
Aplicación móvil nativa desarrollada para Android, diseñada para facilitar la intervención y la comunicación operativa en lengua inglesa para los cuerpos de seguridad. 👮‍♂️💬

## 📊 Estadísticas Lingüísticas y Contenido
* **Módulos temáticos:** 30 bloques especializados. 🗂️
* **Términos de vocabulario:** 3,099 entradas técnicas y operativas. 📚
* **Frases operativas:** 798 locuciones orientadas a situaciones reales de intervención. 🗣️
* **Soporte fonético:** Transcripción fonética integrada para la correcta pronunciación. 🔤

## ⚙️ Características Técnicas
* **Plataforma:** Android (Nativo) 🤖
* **Lenguaje:** Kotlin 💻
* **Interfaz de Usuario:** Jetpack Compose 🎨
* **Funcionalidad de Audio:** Motor integrado de Texto a Voz (*Text-to-Speech*) para la reproducción y práctica de frases operativas. 🔊
